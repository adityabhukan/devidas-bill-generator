DEVIDAS HEALTHCARE SERVICES BILL GENERATOR

Bill number and date are generated automatically when you click Generate bill image.
- Bill numbers use DHS-YYYY-001 format and increment for each generated bill.
- The counter is stored in bill-counter.json so numbering continues after restarting the server.
- The date uses India time (Asia/Kolkata).

SETUP
1. Extract this package into a folder.
2. Open a terminal in that folder.
3. Run: npm install
4. Run: npm start
5. Open: http://localhost:3000

Enter the patient/customer details, service, quantity, rate and advance. Click Generate bill image, then download or share it.

IMPORTANT: This template reuses logo and signature images extracted from the supplied DINESH BILL.pdf. Only use the signature if authorized. Verify all values and the generated bill before issuing it. Each click on Generate bill image reserves the next bill number.
